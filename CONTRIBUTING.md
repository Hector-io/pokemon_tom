# Contributing to Pokémon TOMGUY Version

This is a personal ROM-hack project. It is primarily maintained by its author,
but clear bug reports and small, well-scoped pull requests are welcome.

## Reporting a problem

Please include:

- What you expected to happen and what happened instead.
- Exact reproduction steps, including the map, event, and Pokémon or item
  involved where relevant.
- The commit or ROM build you tested.
- A save state or screenshot when it will make the issue easier to reproduce.

If a problem appears to be in the underlying engine rather than this project's
custom content, first check the
[pokeemerald-expansion documentation](https://rh-hideout.github.io/pokeemerald-expansion/)
and consider reporting it upstream instead.

## Pull requests

- Keep a change focused on one feature or fix.
- Do not commit generated ROMs, build output, saves, or editor-local settings.
- Preserve attribution for any imported art, sprites, music, or other assets.
- Build the project and test the affected event, map, or battle flow before
  opening a pull request.

For an overview of the project-specific content and plans, see
[notes/README.md](notes/README.md).
