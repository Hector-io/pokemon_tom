# Project notes

This directory contains the game-specific planning material. The source code is
authoritative when a note conflicts with it.

| File | Purpose |
| --- | --- |
| [completed_changes.md](completed_changes.md) | High-level features currently present in the source. |
| [todo.md](todo.md) | Organised backlog of unfinished work. |
| [character_plan.md](character_plan.md) | Character, gym, Elite Four, Champion, team, and music plans. |
| `encounter_planned_changes.xlsx` | Original workbook used to plan encounter distribution. |

The generated `encounter_report.csv` at the repository root and
`encounter_report.py` support encounter review. Update them after a substantial
encounter-table pass.
