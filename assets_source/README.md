# Source assets

This directory stores editable artwork, reference sprites, and candidate music
sources for Pokémon TOMGUY Version. It is a working library, not a directory
read directly by the build.

- `title_screen/` contains the editable title artwork.
- `trainer_sprites/` and `overworld_sprites/` contain source and reference art
  for character replacements.
- `music/` contains candidate MIDI and project files that still need conversion
  and in-game testing.
- The FRLG NPC megapack and other imported material remain here with their
  original attribution files where available.

Before moving an asset into `graphics/` or `sound/`, verify its palette, size,
animation requirements, attribution, and permission to redistribute it in a
public project.
